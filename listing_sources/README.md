# listing_sources (Future v0.2)

## 說明
本專案為「台北雙星土地型自住房研究引擎」，核心定位為「本機優先」的歷史成交與地籍空間研究工具（v0.1）。

### 範圍定義
- **本版本（v0.1）**：完全專注於官方真實歷史成交資料（內政部實價登錄）與官方 GIS 圖層（使用分區、道路寬度、地段圖等）。不包含任何民間房仲或售屋網站的即時掛牌爬取。
- **未來規劃（v0.2）**：
  - 預留供未來擴充「現況掛牌資料來源」（如 591、樂屋網、永慶、信義房屋等）的介面規範與適配器（Adapters）。
  - 若在 v0.2 引入外部掛牌資料，將嚴格遵循不捏造、不爬蟲違規、純研究輔助之原則，並維持歷史成交與現況開價完全分離標示。
  - 目前本目錄僅作為架構預留，v0.1 不實作任何掛牌監控或爬蟲程式碼。
